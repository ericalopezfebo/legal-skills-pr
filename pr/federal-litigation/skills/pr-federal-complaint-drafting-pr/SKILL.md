# Demanda federal para Puerto Rico

## Workflow

1. Confirmar tribunal, jurisdicción, venue, standing y remedios autorizados.
2. Organizar partes, hechos numerados y reclamaciones sin alegar inferencias como hechos.
3. Para cada causa de acción, mapear elementos a alegaciones y prueba disponible.
4. Separar Derecho federal, Derecho de Puerto Rico y bases suplementarias.
5. Aplicar reglas de redacción de datos personales y requisitos locales vigentes.
6. Entregar demanda, inventario de anexos, hechos faltantes y checklist de presentación.

## Salida

Entrega un borrador estructurado, hechos faltantes, autoridades verificadas, incertidumbres, riesgos y próximos pasos.
## Fuentes y control de calidad

Antes de usar el resultado, verifica la versión vigente de las reglas federales, las reglas locales, órdenes generales, órdenes del caso, estatutos y precedentes vinculantes. No trates propuestas, materiales de estudio ni autoridades no comprobadas como Derecho vigente. Marca toda cita pendiente como `UNVERIFIED`, minimiza datos personales y exige revisión independiente por abogado.
