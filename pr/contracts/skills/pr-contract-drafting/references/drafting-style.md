# Legal drafting style

Use these principles when producing Puerto Rico legal documents:

- Clarity over ornament.
- Logical organization with descriptive headings.
- Precision: include facts and obligations that matter; remove distracting detail.
- Neutral, professional tone.
- Active voice when it improves clarity.
- Consistent terminology.
- Accurate, traceable citations when citations are appropriate.
- Edit for grammar, spelling, internal consistency and cross-references.
- Write for the actual audience and purpose of the document.

For contracts specifically:
- identify the actor for every material obligation;
- state deadlines and triggering events precisely;
- avoid using multiple terms for the same party or concept;
- distinguish representations, covenants, conditions and remedies;
- avoid undefined standards unless intentional;
- prefer concrete mechanics over vague promises to "cooperate" or "agree later."
