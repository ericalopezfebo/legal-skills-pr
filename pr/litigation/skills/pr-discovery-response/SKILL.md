# Puerto Rico Civil Discovery Responses

## Workflow
1. Identify the discovery device and response deadline.
2. Analyze each request separately.
3. Determine responsive information actually available to the responding party.
4. Identify privilege/work-product/confidentiality issues.
5. Use an objection only when a good-faith legal basis exists.
6. State whether responsive material is being withheld when current law/rules require that clarification.
7. For admissions, answer the proposition directly and qualify only as necessary.
8. Verify current Puerto Rico procedural requirements before finalizing.

## Guardrails
Avoid reflexive boilerplate such as “vague, overbroad and burdensome” without explaining the real defect when explanation is required. Never invent facts to complete a response.
