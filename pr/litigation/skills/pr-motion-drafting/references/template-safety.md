# Using prior motion formats safely

Prior legal documents can teach:
- caption layout;
- heading hierarchy;
- section sequencing;
- signature-block conventions;
- tone and recurring phrasing.

They must not become hidden factual sources.

Before adapting any template:
1. strip matter-specific identifiers;
2. rebuild the factual section from the current matter;
3. re-research authorities that affect the requested relief;
4. verify procedural rules and deadlines as of the current date;
5. remove unused exhibits and cross-references;
6. confirm that the requested remedy matches the present posture.

A template is a drafting example, not precedent.
