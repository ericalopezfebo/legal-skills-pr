# Puerto Rico Civil Discovery Drafting

## Purpose
Create targeted discovery tied to claims, defenses, damages, witnesses, documents and disputed factual issues.

## Workflow
1. Identify claims, defenses and issues that actually require proof.
2. Build an issue-to-evidence map.
3. Select the appropriate discovery device for each information need.
4. Draft requests that are specific, proportional and intelligible.
5. Avoid unnecessary duplication across interrogatories, production requests and admissions.
6. Define terms only when needed.
7. Verify current procedural limits, timing, service and objection rules.
8. Audit for privilege, work product, confidentiality and sensitive information.

## Request design
- Interrogatories: facts, identities, contentions and information not better obtained as documents.
- Production: identifiable document/data categories and relevant ESI.
- Admissions: narrow propositions useful to eliminate genuinely undisputed issues.

## Guardrails
Do not create harassment-oriented discovery, assume facts not supplied, or represent that a request is procedurally permissible without checking the current rule when limits matter.
